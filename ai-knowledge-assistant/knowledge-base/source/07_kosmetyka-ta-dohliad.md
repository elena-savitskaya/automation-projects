# FORMA Barbershop — косметика в продажу та поради з догляду

## Засоби для укладання
- Матова глина (сильна фіксація, матовий ефект): 590 грн. Для текстурних коротких стрижок, кропу.
- Помада на водній основі (середня фіксація, блиск): 520 грн. Для класичних зачісок, змивається легко.
- Паста (середня фіксація, напівматовий ефект): 550 грн. Універсальний варіант для більшості стрижок.
- Сольовий спрей для об'єму: 450 грн. Наноситься на вологе волосся перед феном.
- Пудра для об'єму: 480 грн. Для тонкого волосся.

## Догляд за бородою
- Олія для бороди (кедр та бергамот): 450 грн. 2–3 краплі щодня після душу.
- Бальзам для бороди: 490 грн. Для бороди від 3 см, дисциплінує неслухняні волоски.
- Шампунь для бороди: 420 грн.

## Догляд за волоссям і шкірою
- Шампунь щоденний: 450 грн.
- Кондиціонер: 450 грн.
- Бальзам після гоління: 520 грн.

Учасники FORMA Club отримують знижку 10% на косметику. Косметику можна купити без запису на послугу в робочі години.

## Поради майстрів
- Засіб для укладання беріть розміром з горошину: краще додати, ніж перевантажити волосся.
- Глину й пасту наносьте на сухе волосся, сольовий спрей на вологе.
- Бороду миють спеціальним шампунем 2–3 рази на тиждень, щоденне миття звичайним шампунем сушить шкіру.
- Не підстригайте контур бороди самостійно між візитами: легко «з'їсти» лінію щоки, краще прийти на окантовку.

## Повернення
Нерозпаковану косметику можна повернути протягом 14 днів з чеком. Якщо засіб не підійшов після першого використання, обміняємо на інший (одноразово).
